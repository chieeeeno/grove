# Grove — プロジェクト名選定メモ

> ステータス: 仮決定
> 決定日: 2026-04-07

---

## 選定結果

**Grove（グローブ）** を第一候補として仮決定。

「Grove」は英語で「木立、小さな森」を意味する。Git の worktree（作業木）が複数並んでいる様子が、小さな森に木が立ち並ぶイメージと重なるため採用した。

**選定ポイント:**

- 短くて覚えやすい（5文字）
- worktree の「tree」と自然につながるモチーフ
- CLI コマンド名としても打ちやすい（`grove`）
- npm / crates.io での名前の被りが少ない
- 技術的すぎず、親しみやすい響き
