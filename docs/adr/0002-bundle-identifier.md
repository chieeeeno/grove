# ADR-0002: アプリ識別子を `io.github.chieeeeno.grove` に決定

**日付**: 2026-04-07
**ステータス**: 確定

## 背景

Tauri の `tauri.conf.json` で必須となる bundle identifier。逆ドメイン形式で書く慣習がある。後から変更すると macOS 上でアップデート時に別アプリ扱いになるなど影響が大きいため、早期に確定する必要がある。

## 検討した選択肢

- **A**: `com.tomoki.grove` — シンプル
- **B**: `dev.tomoki.grove` — 開発者ツール系で使われる流派
- **C**: `io.github.chieeeeno.grove` — GitHub アカウント名前空間
- **D**: 独自ドメインを取得して使う

## 決定

**C: `io.github.chieeeeno.grove`**

## 理由

- 「自分が所有する名前空間を使う」というベストプラクティスに従う
- GitHub アカウント `chieeeeno` は実質的に自分が所有する一意な名前空間
- 独自ドメインを持っていない現状でのベストな選択
- `io.github.<user>.<app>` は OSS プロジェクトでよく使われる定番パターンで、他の開発者にも意図が伝わりやすい

## 却下した選択肢の理由

- **A / B**: `com.tomoki.*` や `dev.tomoki.*` は誰でも名乗れる名前空間で、識別子の本来の意図（一意性の保証）に反する
- **D**: 現時点でドメインを所有しておらず、ドメイン取得・更新コストを払うほどの必要性もない
