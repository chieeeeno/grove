# ADR-0004: 対応OSを macOS のみとする（M0 / M1）

**日付**: 2026-04-07
**ステータス**: 確定

## 背景

Tauri はクロスプラットフォーム対応が可能だが、各OSで実機検証・バグ修正・署名/公証作業が必要となる。特に Phase 2 で予定している Claude Code プロセス検知は OS ごとに API が異なるため、対応OS数が実装コストに直結する。M0（自分用 α）と M1（β 配布）の段階で、どこまで対応するかを決める必要がある。

## 検討した選択肢

- **A**: macOS のみ（M0 / M1）
- **B**: macOS + Linux（M1 から）
- **C**: 全OS対応（最初から macOS / Linux / Windows）

## 決定

**A: macOS のみ**（M0 / M1）

Windows / Linux 対応は M2 以降で必要性に応じて判断する。

## 理由

- **開発者本人が macOS しか所有していない** — 他OSの実機検証ができないため、対応してもユーザーに動作保証ができない
- 自分の環境でドッグフーディングが完結する
- Phase 2 のプロセス検知ロジックを 1 パターンで済ませられる
- M1 の β 配布も mac ユーザーの知人に渡せば十分検証になる
- Tauri はクロスプラットフォーム前提で書けるため、後から Linux/Windows 追加もゼロから書き直しにはならない

## 却下した選択肢の理由

- **B**: Linux 実機を持っていないため動作確認ができない。仮想環境での確認は可能だがコストが見合わない
- **C**: Windows も同様に実機なし。検証コストが3倍になり M0/M1 完成が遅れる
