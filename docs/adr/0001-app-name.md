# ADR-0001: アプリ名を「Grove」で確定

**日付**: 2026-04-07
**ステータス**: 確定

## 背景

設計書では「Grove（仮）」表記。リポジトリ名・アプリ識別子・配布チャネル名（Homebrew tap 等）に影響するため、早期に確定したい。命名候補と選定経緯の詳細は [grove-naming.md](../grove-naming.md) を参照。

## 検討した選択肢

- **A**: Grove で確定
- **B**: 別の名前（Canopy, Arbor, Copse, Mori, Graft 等の候補あり）
- **C**: 仮のまま進める

## 決定

**A: Grove で確定**

## 理由

- 「木立、小さな森」の意味が、worktree が並ぶ様子と自然に重なる
- 短くて覚えやすい（5文字）
- worktree の「tree」とモチーフがつながる
- CLI コマンド名としても打ちやすい（`grove`）
- npm / crates.io での名前の被りが少ない
- 技術的すぎず親しみやすい響き

## 却下した選択肢の理由

- **B**: 詳細は [grove-naming.md](../grove-naming.md) の候補一覧参照。Grove より優位な候補が見当たらなかった
- **C**: 意思決定の先送りであり、識別子・リポジトリ名など他の決定がブロックされる
